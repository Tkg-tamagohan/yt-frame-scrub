# 手動確認手順

`docs/requirements-definition.md` と `docs/implementation-plan.md` の受け入れ条件に対応する手動確認の一覧である。
自動テスト（`npm run test`）でカバーされない、実ブラウザと実動画上の挙動を確認する。

## 事前準備

1. リポジトリをクローンし、`npm install` のあと `npm run build` を実行する。
2. Chrome で `chrome://extensions` を開き、右上の「デベロッパーモード」を有効にする。
3. 「パッケージ化されていない拡張機能を読み込む」で `dist/` フォルダを選択する。
4. 拡張がエラーなく登録され、ツールバーにアイコンが出ることを確認する。

## 確認項目

「捕捉」は、スクロールがコマ送りに変換されページスクロールへ流れない状態を指す。
確認は既定設定（有効・常時捕捉・上スクロール=送り・オーバーレイ表示・fps 自動）で行い、別記がない限り watch ページを使う。

| ID | 対象 | 手順 | 期待結果 |
|----|------|------|----------|
| MT-01 | 読み込み | youtube.com の watch ページを開く | コンソールに `[yt-frame-scrub] attached: watch player` が出る |
| MT-02 | コマ送り（FR-1、仕様決定 A） | 動画を一時停止し、プレイヤー上で上スクロール | 1 ノッチごとに 1 コマ進む。ページはスクロールしない |
| MT-03 | コマ戻し（FR-1） | 一時停止中に下スクロール | 1 ノッチごとに 1 コマ戻る |
| MT-04 | 再生中の素通し（FR-5、仕様決定 B） | 再生中にプレイヤー上でスクロール | ページが普通にスクロールし、動画位置は変わらない |
| MT-05 | ホイール蓄積（FR-2） | トラックパッドや高分解能ホイールで小さく連続スクロール | 小刻みなイベントが蓄積され、閾値ごとに 1 コマ進む。指を止めたあとの慣性で意図しない連続送りが起きない |
| MT-06 | Shift 複数コマ（FR-3） | 一時停止中に Shift を押しながらスクロール | 1 ノッチで既定 10 コマ移動する |
| MT-07 | オーバーレイ（FR-4、仕様決定 E） | 一時停止中にスクロール | プレイヤー内にフレーム番号・タイムコード・fps が表示され、操作停止から約 3 秒でフェードアウトする |
| MT-08 | 修飾キーゲート（FR-1、仕様決定 C） | 設定で捕捉条件を「Alt 押下中のみ」に変更し、素のスクロールと Alt+スクロールを試す | 素のスクロールはページスクロールのまま、Alt+スクロールのみコマ送りになる |
| MT-09 | 方向反転（FR-1、仕様決定 A） | 設定で方向を反転し、上スクロール | コマ戻しになる |
| MT-10 | オーバーレイ非表示（FR-6） | 設定でオーバーレイを無効にし、スクロール | コマ送りは動くがオーバーレイは出ない |
| MT-11 | 設定画面（FR-6） | 拡張機能の詳細→「拡張機能オプション」から設定を開く | 全設定項目（有効/無効・方向反転・捕捉条件・閾値・Shift コマ数・オーバーレイ・手動 fps）が表示・編集できる |
| MT-12 | Shift 競合の表示（FR-6） | 設定で捕捉条件に Shift を選択 | 「Shift 併用の複数コマ移動は利用できない」旨の注意が表示される |
| MT-13 | 設定の即時反映（FR-6） | 設定変更後、リロードせずに動作を確認 | 変更がその場で反映される |
| MT-14 | アイコントグル（FR-6） | ツールバーの拡張アイコンをクリック | 有効/無効が切り替わり、無効時はバッジとタイトルで分かる。無効中はコマ送りしない |
| MT-15 | fps 検出（Phase 4 受け入れ） | 30fps と 60fps の動画それぞれで 1 コマ送り | オーバーレイの fps 表示が動画に合い、コマ送りの刻み幅がその fps に対応する |
| MT-16 | 手動 fps（Phase 4 受け入れ） | 設定で手動 fps を指定し、検出に失敗しそうな動画で確認 | 手動値が使われる |
| MT-17 | Shorts（FR-7、仕様決定 D） | `/shorts/` の動画を一時停止してスクロール | watch と同じコマ送りになる。再生中のスクロールは従来どおりフィード遷移する |
| MT-18 | ページ遷移（FR-7） | watch → Shorts → watch と行き来する | 各ページで初期化し直し、機能が壊れない |
| MT-19 | 表示モード追従（FR-7） | 全画面・シアターモード・ミニプレイヤーを切り替えてスクロール | 各モードでコマ送りとオーバーレイ位置が正しい |
| MT-20 | 広告での無効化（対象範囲） | 広告が再生される動画で、広告中にスクロール | コマ送りせず素通しになる |
| MT-21 | ライブでの無効化（対象範囲） | ライブ配信・プレミア公開のリアルタイム再生でスクロール | コマ送りせず素通しになる |
| MT-22 | zip 配布（仕様決定 G） | `npm run pack` で生成した zip を別環境で展開して読み込む | 開発者モードで読み込め、機能が動作する |

## 確認環境の記録

確認した環境（OS、Chrome のバージョン、拡張のバージョン）と実施日、各 ID の合否を記録する。
失敗した項目は発生条件と実際の挙動を添えて報告する。

## 既知の制約

- 実際の広告再生とライブ配信での無効化（MT-20・MT-21）は、実装時点で実環境の検証が済んでいない。
  判定根拠は広告がプレイヤーコンテナのクラス名（`ad-showing` 等）、ライブが動画の `duration` であり、実機での挙動を優先確認する。
- 統計情報パネルの fps 読み取りも実在の表記形式での検証が未完のため、検出に失敗した場合は実測または手動値へフォールバックする仕様になっている。
