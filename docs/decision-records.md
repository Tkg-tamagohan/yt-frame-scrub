# 決定記録

要件定義の協議項目に対する決定を記録する。
項目 ID は協議時の一覧を引き継いだ識別子で、各決定は `requirements-definition.md` 本文にも反映されており、該当箇所に「仕様決定 X」の形で参照を付記している。
他の文書から決定へ言及するときは同じ ID（「仕様決定 A」など）を使う。

| ID | 項目 | 決定内容 |
|----|------|----------|
| A | スクロール方向の既定 | 上スクロール=コマ送り、下スクロール=コマ戻りを既定とする。設定画面の反転オプションで入れ替え可能 |
| B | 再生中のスクロール挙動 | 再生中は捕捉せずブラウザ標準の挙動を通す（何もしない） |
| C | スクロール捕捉の成立条件 | 一時停止中はプレイヤー上で常時捕捉を既定とする。設定で「修飾キー併用時のみ捕捉」に変更可能 |
| D | 対象プレイヤーの範囲 | watch ページ＋Shorts を対象とする。埋め込みプレイヤーと Chrome 以外のブラウザは範囲外（将来候補） |
| E | オーバーレイの既定表示 | コマ送り操作中のみ表示し、操作停止から数秒でフェードアウト |
| F | 初期版の機能範囲 | スクロールコマ送り＋オーバーレイ＋設定画面のみ。コントロールバーボタン、A-B リピート、フレーム保存等は将来候補 |
| G | 配布形態 | ローカル読み込み＋GitHub Release の zip＋Chrome Web Store 公開の 3 経路 |
| H | リポジトリ名 | `yt-frame-scrub` |
| I | ライセンス | MIT |
